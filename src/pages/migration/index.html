1. Repositorio Origen (BaP_Framework) Acceso al framework v2.6.0 como plantilla base limpia.
2. Repositorio Destino (Proyecto Legacy) Acceso de escritura para crear la rama de migración e inyectar el código.

🤖 Fusión No Destructiva de Directivas & Skills (.agents/)

A partir de la versión v2.6.0, el proceso de migración garantiza la integridad de las reglas y habilidades personalizadas del proyecto destino:

  • Habilidades Executables (.agents/skills/): Se copian las habilidades oficiales bap-* (como bap-migration-orchestrator) sin sobrescribir ni eliminar las skills creadas previamente por el desarrollador.
  • Reglas de Desarrollo (.agents/AGENTS.md): Si el proyecto destino ya cuenta con sus propias reglas, se conservan intactas y se integran las normas de BaP bajo la sección ## Directivas del Framework BaP (v2.6.0).
