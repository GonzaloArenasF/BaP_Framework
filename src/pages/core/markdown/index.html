Módulo markdown.js

Parser local y ligero de Markdown a HTML. Convierte sintaxis Markdown (títulos, negritas, listas, enlaces y bloques de código) a marcado HTML previamente sanitizado mediante DOMPurify.

Funciones Exportadas (export function)

1. parseMarkdown(md)

Firma: parseMarkdown(md: string): string

Propósito: Parsea una cadena de texto en sintaxis Markdown y retorna la cadena HTML sanitizada equivalente.

Parámetro Tipo Requerido Descripción
md String Sí Cadena de texto en sintaxis Markdown a transformar en HTML sanitizado.

Ejemplo de uso:

import { parseMarkdown } from "../../_main/markdown.js";

const htmlOutput = parseMarkdown("# Título Principal\n- Elemento 1\n- Elemento 2");
console.log("HTML Sanitizado:", htmlOutput);

Buenas Prácticas

  • Renderizado de documentos: Pasar la salida de parseMarkdown() a elementos contenedores del DOM de forma segura.
