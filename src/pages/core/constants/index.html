Módulo constants.js

Módulo base del núcleo que actúa como la única fuente de verdad para la configuración global de la aplicación, constantes del framework y la resolución dinámica de la URL del servidor.

Atributos Exportados (export const)

1. CONSTANT

Tipo: Object (Inmutable)

Propósito: Objeto inmutable que almacena las constantes globales del framework (nombres de eventos, tipos de notificación, claves de almacenamiento y estados de sesión).

Ejemplo de uso:

import { CONSTANT } from "../../_main/constants.js";

// Acceso a la versión y tipos de notificación
console.log("Versión del Framework:", CONSTANT.APP_VERSION);
console.log("Tipo de alerta:", CONSTANT.NOTIFICATION.TYPE.ALERT);

2. ENV_URL

Tipo: String

Propósito: Calcula dinámicamente la URL base de la aplicación según `window.location.origin` y el puerto activo, evitando colisiones con puertos en macOS.

Ejemplo de uso:

import { ENV_URL } from "../../_main/constants.js";

// Construcción de rutas absolutas
const logoUrl = `${ENV_URL}/assets/images/logo.png`;

3. CDN_URL & IS_PROD

Tipo: String / Boolean

Propósito: `CDN_URL` contiene la ruta al canal de distribución CDN de recursos pesados. `IS_PROD` indica si la aplicación se está ejecutando en el entorno de producción.

Ejemplo de uso:

import { CDN_URL, IS_PROD } from "../../_main/constants.js";

if (IS_PROD) {
  console.log("Cargando recursos pesados desde CDN:", CDN_URL);
}

Buenas Prácticas

  • No hardcodear URLs: Usar siempre `ENV_URL` para construir rutas dinámicas a imágenes, CSS o plantillas.
  • No modificar `CONSTANT`: Tratar el objeto `CONSTANT` como inmutable en tiempo de ejecución.
