Módulo analytics.js

Módulo de telemetría unificada que expone una API declarativa basada en la taxonomía definida en `bap.config.json`.

Atributos Exportados (export const)

1. analytic

Tipo: Object

Propósito: Objeto dinámico exportado que expone funciones tipadas en `analytic.logEvent.*` para cada evento configurado en la taxonomía de la aplicación.

Ejemplo de uso:

import { analytic } from "../../_main/analytics.js";

// Registrar entrada a la vista del Core
analytic.logEvent.enterCorePage?.();

// Registrar evento personalizado con parámetros
analytic.logEvent.searchSubmitted?.({ query: "cifrado AES-GCM" });

Buenas Prácticas

  • Nomenclatura taxonómica: Declarar todos los eventos en `bap.config.json` antes de utilizarlos en componentes.
