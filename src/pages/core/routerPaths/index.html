Módulo routerPaths.js

Catálogo declarativo y estricto de todas las rutas navegables de la aplicación web, asociando URLs con permisos de sesión (`requireAuth`).

Atributos Exportados (export const)

1. NAVIGATION_TYPES

Tipo: Object

Propósito: Tipos de navegación soportados (`REDIRECT` y `LOAD_COMPONENT`).

Ejemplo de uso:

import { NAVIGATION_TYPES } from "../../_main/routerPaths.js";

console.log("Modo de redirección SPA:", NAVIGATION_TYPES.REDIRECT);

2. routes

Tipo: Object

Propósito: Objeto con las rutas configuradas e inyectadas desde `bap.config.json` durante la compilación con Gulp.

Ejemplo de uso:

import { routes } from "../../_main/routerPaths.js";

// Inspeccionar configuración de la ruta del Core
console.log("Ruta Core:", routes.core.pathname);
console.log("Requiere Auth:", routes.core.validate?.signIn);

Buenas Prácticas

  • Registrar siempre las nuevas vistas: Declarar la ruta en `bap.config.json` antes de crear nuevas páginas HTML.
